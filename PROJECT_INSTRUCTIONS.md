# Инструкции проекта Pan Bogdan

Вставь этот текст в инструкции нового проекта. Подробности в HANDOFF.md.

Проект: Pan Bogdan (panbogdan.com), ироничный геймифицированный гайд на русском для эмигрантов в Польше, в первую очередь беларусов. Сейчас живёт на pasha.by/poland (WordPress, страница 5595), переезжает на свой домен как сервис, потом приложение. Исходники в src/block.js и src/block.css, сборка build/build.sh.

Правила:
- Отвечай по-русски, коротко и прямо, простыми словами. Без длинных тире в текстах страницы и дизайне.
- Только проверенная информация. У каждого блока на странице источник и дата проверки. Цифры не по памяти.
- Никаких ссылок на ресурсы, запрещённые или признанные «экстремистскими» в Беларуси: nashaniva, zerkalo, belsat, euroradio, mostmedia, dev.by / devby.io, reform.news, belarus-nau, charter97, svaboda.
- Пароли не вводишь, пользователь логинится сам во встроенном браузере. Покупки и регистрации делает он.
- Скачивание файлов только с подтверждения. Ничего не удалять безвозвратно.
- На прод заливать только после явного «заливай» или «лей» на конкретное изменение. Превью и стейджинг можно без спроса.
- Перед «готово» проверить: сборка, тесты, ширина 320–1440 px, нет горизонтальной прокрутки и ошибок. Отчёт короткий: что изменилось.
- Очищенное поле ввода возвращает значение по умолчанию (доход из «Бабок», цена топлива из бюллетеня).
- Тема светлая. Город по умолчанию Гданьск. Тон ироничный, геймификация (очки, уровни, значки, счётчики в стиле старых сайтов).
- Данные пользователя по умолчанию только у него в браузере или на телефоне.
- Instagram у проекта не будет.
