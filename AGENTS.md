# AGENTS.md: Pan Bogdan

Файл для любого ИИ-агента в этом репозитории (ChatGPT / Codex, Claude). Над проектом работают **по очереди, не параллельно**: в каждый момент код меняет только один агент. Подробности о проекте в `HANDOFF.md`, журнал ходов в `TURNS.md`.

## Что это

panbogdan.com: ироничный геймифицированный гайд на русском для эмигрантов в Польше, в первую очередь беларусов. Статический сайт на Cloudflare Pages, без фреймворков. Весь гайд в `src/block.js` и `src/block.css`, данные внутри `block.js`. Прогресс пользователя только в его браузере (localStorage `pb-poland-v2`).

## Правила (обязательные)

- Отвечай Павлу по-русски, коротко и прямо, простыми словами.
- В текстах сайта и в дизайне **нет длинных тире** (—). Тест `t15.js` это проверяет.
- Только проверенная информация. У каждого блока источник и дата проверки (`srcLine`, `SOURCES`). Цифры не по памяти: найди, открой, сверь. Нет пруфа, не пиши.
- **Не ссылаться** на ресурсы, запрещённые или «экстремистские» в Беларуси: nashaniva, zerkalo, belsat, euroradio, mostmedia, dev.by / devby.io, reform.news, belarus-nau, charter97, svaboda. Это риск для читателей.
- Написание: «беларус», «по-беларуски», «беларуский» (одна «с»). В пользовательском интерфейсе использовать термин «dokument podróży» вместо русского «документ путешествия» или прозвища «Документ Подружи».
- Пароли не вводить. Покупки, регистрации, оплаты и действия в панелях Cloudflare/GitHub с логином делает Павел.
- Ничего не удалять безвозвратно. Файлы скачивать только с подтверждения. `git push --force` и переписывание истории запрещены.
- **Прод (`main`) только после явного «заливай» или «лей»** на конкретное изменение. `redesign` и `staging` можно без спроса.
- Перед «готово»: сборка, тесты, ширина 320–1440 px, нет горизонтальной прокрутки, нет ошибок в консоли. Отчёт короткий: что изменилось.
- Очищенное поле ввода возвращает значение по умолчанию (доход из «Бабок», цена топлива из бюллетеня).
- Тема только светлая. Город по умолчанию Гданьск. Красный бренда #D74B4E, текст #1F1919. Шрифт IBM Plex Sans (свой хостинг). Значки только из набора Павла (`ICONS`, `ICONS18`); нужного нет, попроси у Павла, не рисуй свой.
- Данные пользователя по умолчанию только на его устройстве. Instagram у проекта не будет.

## Ветки и деплой

| Ветка | Куда | Когда |
|---|---|---|
| `redesign` | рабочая | всегда |
| `staging` | https://staging.panbogdan.pages.dev | без спроса, для проверки |
| `main` | https://panbogdan.com (автодеплой Cloudflare Pages, папка `site/`) | только после «лей» |

```bash
git fetch origin
git switch redesign && git merge --ff-only origin/redesign
# ... правки ...
cd build && ./build.sh && python3 mksite.py && cd ..
git add -A && git commit -m "Раздел: что сделано"
git push origin redesign redesign:staging          # стейджинг, ~75 с на сборку
# только после «лей»:
git merge-base --is-ancestor origin/main HEAD && git push origin HEAD:main
```

`site/` собирается и коммитится (Cloudflare не собирает сам). При пересборке в `site/*.html` меняется случайная фраза шапки: если других изменений нет, откати `git checkout -- site`.

## Сборка и тесты

- Нужны python3 и node 20+. `cd build && npm install` (terser, csso, jsdom).
- `cd build && ./build.sh`: `dist/preview.html` (превью, адреса через `#dom`) и `dist/poland-wp.html` (WordPress-версия, больше не на проде).
- `python3 build/mksite.py`: `site/` со страницей на каждый раздел (`/legalizacja`, `/aktualnosci`, `/bialorusini`, `/pieniadze`, `/banki`, `/dzieci`, `/dom`, `/auto`, `/pomoc`, `/slownik`), пререндер текста через `build/prerender.js`.
- Тесты jsdom: `NODE_PATH=build/node_modules node tests/t5.js` (и t9, t13, t14, t15). `node tests/mortval.js` проверяет модель ипотеки.
- `tests/tm1–tm5.js` на Playwright: нужен `npm i playwright && npx playwright install chromium`.
- Известное на 20.11.2026: в `t15.js` падает одна проверка «full document list plus timing rows» (сроки dokument podróży есть только для 4 воеводств). Остальное зелёное.

## Как устроен код (коротко)

- `src/block.js`: IIFE. Сначала данные (`SECTIONS`, `STAGES`, `NEWS`, `LEGAL`, `PAY`, `DOC_INFO`, `BANKS`, `SOURCES`, `PHRASES`...), потом отрисовка `r*()` и пересчёт `update*()`.
- Состояние `S = Object.assign({}, DEF, load())`, поля в `S.f`, умолчания в `DEF.f`. Ввод через `data-f`, общий `setField()`, вывод `out('имя', html)` в `data-o`.
- Роутинг: `show()`, `route()`, History API. Новости открываются попапом по `/aktualnosci#<id>` (`rNewsPop`, `nwpOpen`).
- `NEWS` между маркерами `/*NEWS*/`: робот `build/newscheck.mjs` их парсит, не ломай формат.
- Еженедельные роботы (GitHub Actions, понедельник): `paycheck.yml` (реквизиты ужондов) и `newscheck.yml` (ссылки новостей). Они коммитят в `main` сами.
- Форма связи: `functions/api/feedback.js` пишет в KV `FEEDBACK`; письмо через воркер `workers/mail` пока не подключено в панели (см. HANDOFF, раздел 9).

## Протокол хода

**Начало хода**
1. `git fetch origin`, переключись на `redesign`, перемотай на `origin/redesign`. Если `origin/main` впереди (роботы), влей его: `git merge --ff-only origin/main` или обычный merge.
2. Прочитай последнюю запись в `TURNS.md`: что сделал прошлый агент, что не закончено, что просили не трогать.
3. Незакоммиченных чужих изменений быть не должно. Если есть, не трогай и спроси Павла.

**Конец хода**
1. Сборка, тесты, проверка ширин. Всё закоммичено, `redesign` и `staging` запушены.
2. Добавь запись в начало журнала в `TURNS.md` по шаблону оттуда.
3. Если поменялось устройство кода, правила или беклог, обнови `HANDOFF.md` (новый раздел сверху, старое не стирать).
4. Если пушить нельзя (нет доступа), сделай `git format-patch origin/redesign` и отдай Павлу файлы патча вместе с записью для `TURNS.md`.

Ход заканчивается, когда Павел передаёт работу другому агенту. Не начинай новую задачу сверх просьбы.
