# BEL / UKR: локализация и юридические сценарии
Проверка: 2026-11-21. Статус: исследование, не готово к публикации.

## Принцип
- РУС: существующий гайд, без изменения.
- БЕЛ: полный перевод всего интерфейса и контента на беларускую мову, включая ошибки, формы, калькуляторы, дату, числа, подсказки, новости, словарь и SEO. Законодательные сценарии такие же, как для текущей аудитории. Нельзя смешивать язык и гражданство.
- УКР: полный перевод на українську мову, но в меню вместо «Беларусам» отдельный раздел «Українцям» с другими правилами и источниками. Ни один белорусский документ/статистика/банковский рейтинг не должны отображаться как украинские факты.
- Значения из localStorage pb-poland-v2 не сбрасывать. Текущая страна происхождения и язык должны быть независимы от stage / city / legal. Нельзя менять права пользователя только по языку.
- Переключение языка без reload, с сохранением открытого раздела, URL, статуса чеклистов и калькуляторов. Для SEO отдельные /be/ и /uk/ и hreflang (ru,be,uk), локализованные title/description/og, соответствующий html lang.
- Новостям нужны общие сообщения и фильтруемые по группе; переводы заголовков и текста без потери URL и проверок робота.
- Полный регрессионный тест на 320, 375, 768, 1440 px и проверки всех строк интерфейса на пропущенные RU фразы.

## УКР: проверенные факты для отдельного раздела
1. **PESEL UKR / тимчасовий захист.** Для лиц под временной защитой подтверждённый статус UKR допускает законное пребывание до 4 марта 2027 года. Нельзя приравнивать его к обычному ВНЖ и нельзя обещать его всем гражданам Украины.
   Источники: https://www.gov.pl/web/rodzina/co-sie-zmienia-w-pomocy-dla-obywateli-ukrainy-w-2026-r ; https://mos.cudzoziemcy.gov.pl/kategorie-informacji/mozliwosci-legalizacji/rozwiazania-ob-ukrainy/ustawa-o-ochronie/
2. **Подтверждение личности.** Если PESEL UKR был получен только по заявлению без предъявления действующего заграничного паспорта, нужно было предъявить паспорт в gmina до 31.08.2026. Последствия и порядок восстановления проверять индивидуально; не показывать эту истёкшую дату как будущий дедлайн.
   Источник: https://www.gov.pl/web/udsc/wazna-informacja-dla-obywateli-ukrainy-posiadajacych-numer-pesel-ze-statusem-ukr
3. **CUKR.** Отдельный путь трёхлетней карты пребывания для лиц, отвечающих условиям; подача через MOS/login.gov.pl. Нужна проверка критериев по официальной процедуре, не утверждать, что любой PESEL UKR автоматически даёт CUKR. После получения карты статус UKR меняется на CUKR. Для выезда из Польши более чем на 6 месяцев указана потеря этого разрешения.
   Источники: https://www.gov.pl/web/udsc/CUKR-procedura ; https://www.gov.pl/web/udsc/cukr-QA
4. **Работа.** Для лиц под временной защитой работодатель уведомляет urząd pracy через praca.gov.pl в течение 7 дней с начала работы. Для граждан Украины на иных законных основаниях действуют отдельные переходные положения, в том числе до 04.03.2029; не смешивать группы.
   Источник: https://www.pip.gov.pl/dla-pracodawcow/niezbednik-pracodawcy/ustawa-z-dnia-23-stycznia-2026-r-o-wygaszeniu-rozwiazan-wynikajacych-z-ustawy-o-pomocy-obywatelom-ukrainy-w-zwiazku-z-konfliktem-zbrojnym-na-terytorium-tego-panstwa-oraz-o-zmianie-niektorych-innych-ustaw
5. **800+.** С февраля 2026 новые требования для получателей PESEL UKR, включая проверку трудовой активности; для прочих иностранцев из третьих стран аналогичные условия с периода выплат с июня 2026. Школа/обучение ребёнка и исключения должны проверяться по актуальной странице ZUS. Не писать «все украинцы получают 800+».
   Источники: https://www.zus.pl/pl/swiadczenia/swiadczenia-dla-rodzin/swiadczenie-wychowawcze-800-plus/zmiany-w-swiadczeniu-wychowawczym-program-rodzina-800- ; https://www.gov.pl/web/rodzina/nowe-zasady-przyznawania-swiadczenia-wychowawczego-cudzoziemcom
6. **NFZ.** Доступ к медпомощи не отождествлять с PESEL UKR без проверки текущих критериев после 05.03.2026.
   Источник: https://www.gov.pl/web/ochrona/opieka-medyczna
7. **Новости.** Разграничивать общепольские изменения и изменения только для PESEL UKR; новость о CUKR не показывать как обязательный этап для каждого украинца.
8. **Банки / авто / паспорт.** Удалить беларусо-специфичные санкции, переводы из Беларуси, беларуские автомобильные номера, польский dokument podróży для беларусов, Karta Polaka как автоматическое национальное право, статистику беларусов. Заменять только отдельно проверенными украинскими условиями.

- Структура проверок и юридических шагов для UKR не переиспользует неверные беларусо-специфичные условия.
- Изолированы все пользовательские строки из src/block.js; тест на отсутствие русского текста в обоих переводах (кроме цитат и имён собственных).
- Проверены даты, суммы и ссылки, даты проверки рядом с источниками.
- build/build.sh, mksite.py, jsdom, Playwright, console, горизонтальная прокрутка.
- staging доступен и показывает обе версии на реальном URL; main не изменён.
